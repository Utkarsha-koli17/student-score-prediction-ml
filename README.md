# Student Score Prediction using Machine Learning

## Project Overview
This is a beginner-level Machine Learning mini-project that predicts a student's exam score based on study hours, attendance, sleep hours, previous score, practice tests, and internet access.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning Algorithm
Linear Regression

## Project Steps
1. Load and explore the dataset.
2. Clean and prepare the data.
3. Split the data into training and testing sets.
4. Train a Linear Regression model.
5. Evaluate the model using the R² score.
6. Predict a student's exam score.

## Dataset
The dataset contains 3,000 synthetically generated student records for learning and practice.

## Result
The model predicts an estimated exam score based on the student's details.

## Disclaimer
This project is created for educational purposes. The dataset is synthetic and does not represent real student records.
